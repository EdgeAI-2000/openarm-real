# Local datasets / 本地数据

- `raw/`: OpenArm recordings created by `run.sh` / 原始录制。
- `lerobot/`: converted datasets created by `convert.sh` / 转换结果。

Both directories are created when needed and ignored by Git. Preserve complete dataset directories, including metadata, episodes, images and trajectories, when transferring them.

两个目录按需创建，不上传 Git。迁移数据时应保留完整目录及元数据、episode、图像和轨迹。
